# Videogame Making Club 

The **Videogame Making Club** (aka: *VMC* or *‘The club’*), focuses on channeling the artistic creativity of the kid towards a task in making videogames. For example, kids with artistic ideas will take the role of art designer and will create a character or a location for a game, while kids interested in coding will focus on creating the mechanics of a game.

At the end of the club, the kids are expected to have a slice of a game, with specific parts created by them, depending on their roles. This means a game could have no music, because nobody expressed interest in that part.

This is not a training program, where kids learn to build a complete videogame from scratch. Instead, **VMC** pays attention to the kids' authentic interests and finds suitable roles to express themselves.

# The Tools 

The club uses **Pico-8** (https://www.lexaloAle.com/pico-8.php), a fantasy console to develop and share tiny games. It feels like a console but is a program that can run on desktops and web. Pico8 has built-in tools for editing code, music, sound, sprites and maps. You can create a whole game or program in one sitting without needing to leave the development environment.

VMC uses the free web educational version: https://www.pico-8-edu.com
